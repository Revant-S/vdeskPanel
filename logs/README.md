# Decision log

Records of planning, review and arbitration for the Vault build.

- `decisions/01-plan.md`: the planner's implementation plan
- `decisions/02-review.md`: the reviewer's problems with the plan
- `decisions/03-arbitration.md`: the arbiter's ruling on each conflict
- `decisions/build-log.md`: decisions and conflicts that came up during the build
- `decisions/steps/<step>.md`: notes from the agent that built a step on its own branch
